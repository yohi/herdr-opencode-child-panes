このマニュアルでは、`herdr-opencode-child-panes` の日々の運用をカバーします。正確な動作については [SPEC.md](../SPEC.md) を、セットアップについては [getting-started.md](../docs/getting-started.md) を参照してください。

## 監視 / 期待されるログ

このプラグインは、ライフサイクルイベントと警告をログに出力します。

- 子セッションの登録（`waiting_activity`）。
- ペインの分割とアタッチの試行。
- アタッチの成功または失敗。
- アイドルタイマーの開始とキャンセル。
- ペインのクローズと最終状態（`closed`、`failed`、`ignored`）。

`HERDR_CHILD_PANES_DEBUG` を有効にすると、セッションや前提条件の一部、ライフサイクルの判断、アイドルタイマーの診断情報、認証情報と URL のクエリおよびフラグメントを除去したアタッチコマンドなど、追加の診断ログが出力されます。Herdr CLI の出力はログに記録されません。

## アイドルタイムアウトの動作

子ペインは、`HERDR_CHILD_PANES_IDLE_MS` ミリ秒（デフォルト `10000`）アイドル状態が続いた後に閉じられます。

- `idle` を含む `session.status` または `session.idle` イベントでアイドルがトリガーされます。
- 新しいアクティビティ（`message.updated` または `message.part.updated`）があれば、クローズタイマーはキャンセルされ、ペインはアタッチされたままになります。
- タイマーはメモリ上にあります。OpenCode が再起動すると、保留中のタイマーは失われます。すでにアタッチされているペインは、セッションが削除されるか再びアイドルになるまで開いたままです。

## 容量制限

同時に管理する子ペインの最大数は、`HERDR_CHILD_PANES_MAX`（デフォルト `4`）で制御されます。

- 上限を超えた要求は、理由 `capacity_limit` で `ignored` として記録されます。
- 子セッション自体には影響せず、可視化だけがスキップされます。
- 容量はライブなペインレイアウトから数えられます。外部で閉じられたペインは容量を解放します。
- ミューテーションは直列化されるため、並行イベントで上限を超過することはありません。

## リトライと失敗の動作

- **分割失敗**: セッションは `failed` に移行します。子セッションは引き続き実行されます。
- **アタッチ失敗**: 孤立ペインを避けるため、直後に分割したペインを閉じ、セッションを `failed` に移行します。
- **クローズ失敗**: バックオフ付きで有界リトライされます。リトライを使い切ると、セッションは理由 `close_failed` で `failed` に移行します。
- Herdr CLI のエラーは OpenCode をクラッシュさせることはありません。プラグインは警告をログに出力し、影響を受けた子の処理を停止します。

## セキュリティに関する注意

- `herdr pane run` に渡すコマンドはシェル引用されるため、イベント由来のセッション ID からシェル構文を注入できません。
- アタッチログには、サーバー URL を origin までに短縮したもののみ表示されます。クレデンシャル、クエリ文字列、フラグメントはログに残りません。
- `OPENCODE_SERVER_PASSWORD` と `OPENCODE_SERVER_USERNAME` は `opencode attach` 子プロセスへのみ継承されます。プラグインが読み取ったり保存したりすることはありません。
- プラグインは `HERDR_PANE_ID` 外のペインを調査またはクローズすることはありません。

## 現在の制限

- 使用する分割方向は `right` と `down` のみで、Herdr の対応方向に一致します。
- アイドルタイマーはメモリ上にあり、OpenCode の再起動時に失われます。
- `message.part.delta` イベントは防御的に処理されますが、現行 SDK のイベント union には含まれません。
- 実 Herdr バイナリを使う統合テストは `HERDR_BINARY` 環境変数でゲートされ、未設定時はスキップされます。
- ネストした子セッションも追跡されますが、可視化の深さは同じ容量上限の対象であり、深さ優先の順序は保証されません。

## トラブルシューティングチェックリスト

| 症状 | 確認項目 |
| --- | --- |
| ペインが表示されない | `HERDR_ENV` と `HERDR_PANE_ID` が存在すること、`HERDR_CHILD_PANES` が無効化されていないこと。 |
| ペインは開くが空欄のまま | 新しいペイン内で `opencode` が `PATH` 上にあり、OpenCode サーバーに到達できること。 |
| ペインが多すぎる | `HERDR_CHILD_PANES_MAX` の値と現在のライブレイアウト。 |
| アイドルなペインが開いたまま | `HERDR_CHILD_PANES_IDLE_MS`、新しいアクティビティでタイマーがリセットされていないか。 |
| アタッチログにサーバー詳細が表示されない | 仕様通り: クレデンシャルとクエリ文字列は意図的に削除されています。 |
| 外部で閉じたペインでプラグインの動作がおかしくなる | OpenCode を再起動し、新しい子のレイアウト状態を再構築します。 |
