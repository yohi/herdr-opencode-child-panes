## Review Focus

- Same root opened concurrently via equivalent endpoint aliases: one owner or both safely disabled if equivalence cannot be established (Task 2).
- Root route switches while split/attach is queued: old authority revoked, no operation on new root or reused pane (Task 2/4).
- Server restart or owner crash while managed panes remain: no takeover that duplicates/operates on unproven panes (Task 2).
- Target deleted or recreated between existence check and navigation/attribution: never create a session, reject stale target, clean only proven pane (Task 3).
- Event delivery interrupted, delayed deletion or old-generation events after reload: no stale resurrection; degraded state until authoritative reconciliation (Task 4).
